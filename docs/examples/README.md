# Примеры прогонов дайджеста

В файле `digest-ai-ml-7d.md` находится реальный прогон агента за 2026-06-13, сгенерированный моделью `openai/gpt-oss-120b:free` через OpenRouter в режиме Hermes CLI one-shot (`hermes -z "..."`), без участия Telegram. Агент вызвал MCP-инструменты `search_habr` и `fetch_article` против реального Habr, получил 20 кандидатов, аннотировал 5 статей и собрал связную русскоязычную обзорную статью со вводкой, аннотациями и выводом. Через Telegram-канал дайджест генерируется тем же самым способом — запрос приходит от пользователя в бот, Hermes обрабатывает его, вызывает те же MCP-инструменты и отправляет ответ обратно в чат; воспроизвести можно командой `docker compose up` после настройки `.env`.

**Дедупликация (L3):** второй прогон с тем же запросом не запускался для экономии квоты OpenRouter (~50 req/day на free-tier). Механизм дедупа основан на памяти Hermes: skill записывает ID показанных статей под ключом `digest:<chat_id>:<тема-slug>` и при следующем запросе исключает их из выборки. При использовании через Telegram дедуп работает автоматически между сессиями.
